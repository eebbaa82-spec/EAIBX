Excel-Based Financial Reporting

Module 03 / 6 · 70 min

Turn one clean transactions table into an automated income statement, pivot table analysis and a one-page management dashboard that refreshes every month.

In this module

  1. 1.One clean transactions table
  2. 2.An automated income statement with SUMIFS
  3. 3.XLOOKUP and INDEX/MATCH for budgets and mappings
  4. 4.Pivot tables in practice
  5. 5.Designing a one-page dashboard
  6. 6.Checks, controls and the monthly refresh
  7. ✓Module quiz

In this module you will learn to

  • Structure a transactions table that every report can read, with an Ethiopian-month period column
  • Build an automated income statement with SUMIFS and pull budgets and mappings with XLOOKUP or INDEX/MATCH
  • Summarize transactions with a pivot table, slicers and refresh
  • Design a one-page dashboard with KPI tiles, charts, conditional formatting and an exceptions list
  • Add check cells and controls so automated reports can be trusted
