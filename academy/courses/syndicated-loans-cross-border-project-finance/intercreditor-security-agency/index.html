Intercreditor terms, security and agency administration

Module 04 / 5 · 65 min

Rank and share security among lenders under Ethiopian law, and run the agency from drawdown to default.

In this module

  1. 1.Ranking debt: senior, subordinated and pari passu
  2. 2.Security under Ethiopian law, and its limits
  3. 3.Running drawdowns as agent
  4. 4.Computing interest and distributing payments
  5. 5.Waivers, amendments and monitoring
  6. 6.Managing a default in a syndicate
  7. ✓Module quiz

In this module you will learn to

  • Design intercreditor terms for senior and subordinated debt and for domestic and DFI tranches
  • Explain how security is taken and shared under Ethiopian law, and its limits
  • Process drawdowns and compute and distribute interest as agent
  • Handle waivers, amendments, partial payments and defaults fairly among lenders
