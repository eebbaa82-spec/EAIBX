Excel for analysis: cleaning, formulas and lookups

Module 03 / 5 · 70 min

Turn a raw extract into a clean, checked table and answer questions with summary formulas and lookups.

In this module

  1. 1.Set up before you clean
  2. 2.Cleaning text and numbers
  3. 3.Dates, duplicates and test rows
  4. 4.Core formulas: SUMIFS, COUNTIFS, AVERAGEIFS and IF
  5. 5.Lookups: XLOOKUP and VLOOKUP
  6. 6.A lookup in practice: loan classification and provisions
  7. ✓Module quiz

In this module you will learn to

  • Set up a raw extract as an Excel table and keep the original untouched
  • Clean text, numbers and dates with TRIM, SUBSTITUTE, VALUE and Remove Duplicates
  • Summarize data with SUMIFS, COUNTIFS, AVERAGEIFS and IF
  • Join tables with XLOOKUP or VLOOKUP and check the results
  • Apply a lookup table to compute loan provisions by classification
