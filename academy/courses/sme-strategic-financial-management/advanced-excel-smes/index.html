Advanced Excel for SMEs

Module 05 / 6 · 65 min

Build a clean, checkable financial model in Excel with a scenario switch, sensitivity tables, loan and lease schedules, a KPI dashboard and a monthly monitoring routine.

In this module

  1. 1.Financial models: structure before formulas
  2. 2.Linking the statements and building checks
  3. 3.Scenario switch, sensitivity tables and Goal Seek
  4. 4.Building loan and lease schedules
  5. 5.Dashboards that managers actually read
  6. 6.KPI monitoring systems: data in, decisions out
  7. ✓Module quiz

In this module you will learn to

  • Structure a financial model into inputs, calculations and outputs with clear formatting rules
  • Link the three statements and build error checks, including a balance check
  • Add a scenario switch, sensitivity tables and Goal Seek to test the plan
  • Build loan and lease schedules that feed interest and debt into the statements
  • Design a one-page KPI dashboard and a monthly monitoring routine with controlled data
