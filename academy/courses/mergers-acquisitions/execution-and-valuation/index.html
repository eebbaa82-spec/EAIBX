← Mergers and Acquisitions (M&A) Strategy and Execution

Running the process and valuing the deal

Module 03 / 5 · 65 min

Design a buy-side or sell-side process, manage bidders and data rooms, and value a target with control premium, synergy value, a merger model and a share-for-share exchange ratio.

In this module

  1. 1.Mandates, long lists and the choice of process
  2. 2.Process letters, data rooms and bidder management
  3. 3.Control premium and synergy value
  4. 4.Merger model and walk-away price
  5. 5.Share-for-share exchange ratios
  6. ✓Module quiz

In this module you will learn to

  • Choose between an auction and a bilateral negotiation and design the process letter and data room
  • Manage bidders to keep competitive tension without losing credibility
  • Value control and synergies, and set a walk-away price
  • Build and negotiate a share-for-share exchange ratio for Bank A and Bank D
