Building a Simple Excel Accounting System

Module 04 / 6 · 70 min

Build the nine-sheet bookkeeping workbook step by step: worksheets and layout, a chart of accounts with data validation, the income tracker and the expense tracker, and SUMIFS summaries.

In this module

  1. 1.Planning the workbook
  2. 2.Creating the worksheets
  3. 3.Data entry structure and data validation
  4. 4.The income tracker
  5. 5.The expense tracker
  6. 6.Summarizing with SUM and SUMIFS
  7. ✓Module quiz

In this module you will learn to

  • Plan a bookkeeping workbook of linked worksheets and set up headings, formats and protection
  • Apply data entry rules and data validation lists so entries stay clean
  • Build an income tracker that splits VAT from VAT-inclusive sales
  • Build an expense tracker with totals, withholding and automatic checks, and summarize both with SUMIFS
