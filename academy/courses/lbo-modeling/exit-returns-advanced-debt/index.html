← Leveraged Buyout (LBO) Modeling

Exit, returns and advanced debt structures

Module 03 / 5 · 70 min

Value the exit, compute and attribute IRR and MOIC, test their sensitivity, then build the multi-tranche structure of the capstone deal with PIK mezzanine, a revolver, amortization profiles and covenant tests.

In this module

  1. 1.Exit value, IRR and the money multiple
  2. 2.Sensitivity to price, exit multiple and leverage
  3. 3.Returns attribution: which lever did the work
  4. 4.The capstone structure: multiple tranches and PIK
  5. 5.Revolvers and amortization profiles
  6. 6.Covenant tests and headroom
  7. ✓Module quiz

In this module you will learn to

  • Compute exit equity value, IRR and money multiple, and explain when each can mislead
  • Build a sensitivity table of returns to entry multiple, exit multiple and leverage
  • Attribute equity gains to EBITDA growth, multiple change and deleveraging
  • Model multiple tranches with PIK interest, a revolver and different amortization profiles
  • Test maintenance covenants year by year and measure headroom
