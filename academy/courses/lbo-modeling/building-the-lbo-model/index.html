Building the model: sources and uses to cash sweep

Module 02 / 5 · 70 min

Build Sululta Dairy's LBO model step by step: sources and uses, a nominal birr operating model, free cash flow, a debt schedule with a cash sweep, and the interest circularity that links them.

In this module

  1. 1.The architecture of an LBO model
  2. 2.Sources and uses for Sululta
  3. 3.The operating model in nominal birr
  4. 4.From EBITDA to cash available for debt
  5. 5.The debt schedule and the cash sweep
  6. 6.Interest circularity and how to control it
  7. ✓Module quiz

In this module you will learn to

  • Lay out an LBO model so that every number flows from one assumptions sheet
  • Build a sources and uses table that balances, including fees and minimum cash
  • Project revenue, EBITDA and free cash flow in nominal birr with explicit inflation and working capital assumptions
  • Build a debt schedule with mandatory amortization and a cash sweep, and handle interest circularity safely
