What Project Lending Is and the Project Cycle

Module 01 / 5 · 50 min · Free preview

A project loan is repaid by a business that does not exist yet, so the bank judges the plan, the people and the structure instead of a track record.

In this module

  1. 1.A loan to a business that does not exist yet
  2. 2.Working capital loan versus project loan
  3. 3.The seven stages of the project cycle
  4. 4.The bank's rules for long-term and project loans
  5. 5.Is it really a project loan?
  6. 6.Screening a pile of requests
  7. ✓Module quiz

In this module you will learn to

  • Explain why a project loan is repaid from future cash flow rather than an existing trading cycle
  • Compare project loans and working capital loans on repayment source, evidence, tenor, risks and disbursement
  • Name and describe the seven stages of the project cycle
  • Apply a typical Ethiopian bank manual's rules on long-term loans, grace periods and project loan eligibility
