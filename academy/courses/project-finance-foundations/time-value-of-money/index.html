Time Value of Money for Project Decisions

Module 04 / 5 · 60 min

A Birr received in year 8 is worth much less than a Birr today, and that one idea drives loan installments, payback and NPV.

In this module

  1. 1.Future value and present value
  2. 2.Annuities and loan installments
  3. 3.Choosing the discount rate
  4. 4.Payback and NPV
  5. 5.Case study: Project X or Project Y?
  6. ✓Module quiz

In this module you will learn to

  • Calculate future value and present value
  • Use the annuity factor to compute equal loan installments
  • Compute payback and simple NPV and explain what each tells the bank
  • Choose between projects and explain how cash flow timing shapes the loan structure
