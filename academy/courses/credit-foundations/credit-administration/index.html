Credit administration and capstone

Module 05 / 5 · 65 min

An approved loan is still unprotected until contracts are signed correctly, collateral is registered and insured, and the file is complete.

In this module

  1. 1.The LAF, the decision letter and appeals
  2. 2.Contracts and signatures
  3. 3.Registering collateral before disbursement
  4. 4.Insurance and disbursement
  5. 5.Files and renewals
  6. 6.Spot the errors in a loan file
  7. 7.Capstone: the Kidist Bakery file
  8. ✓Module quiz

In this module you will learn to

  • Prepare the LAF and a written decision letter with all conditions
  • Execute loan and mortgage contracts with the right signatures and stamp duty
  • Register and insure collateral before disbursement
  • Disburse in the correct order and keep the credit and safe custody files
  • Handle renewals at the same, reduced and increased limits
