Project finance appraisal

Module 01 / 5 · 65 min · Free preview

Test whether a large project earns its cost of capital and whether its debt can be serviced on the proposed terms.

In this module

  1. 1.A good project is not always a good loan
  2. 2.Measuring return: NPV, IRR and payback
  3. 3.Sensitivity: how fragile is the project?
  4. 4.Project loan terms in the manuals
  5. 5.Can the debt be serviced? The DSCR test
  6. 6.Restructuring the deal and setting conditions
  7. ✓Module quiz

In this module you will learn to

  • Check a project against the six feasibility tests before any numbers are run
  • Compute and interpret NPV, IRR and payback for a project loan request
  • Stress the project with sensitivity tests and judge how fragile it is
  • Structure equity, tenor, grace and repayments so that DSCR stays comfortably above 1
  • Set disbursement and other conditions that protect the bank during implementation
