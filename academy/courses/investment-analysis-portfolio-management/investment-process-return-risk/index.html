The investment process, return and risk

Module 01 / 5 · 60 min · Free preview

Set objectives and constraints in an investment policy statement, then measure return and risk the way an Ethiopian investor actually experiences them: after inflation.

In this module

  1. 1.The investment process
  2. 2.Objectives and constraints in an IPS
  3. 3.Investor types in Ethiopia
  4. 4.Holding-period return
  5. 5.Nominal and real returns under high inflation
  6. 6.Measuring risk: standard deviation and beyond
  7. ✓Module quiz

In this module you will learn to

  • Describe the investment process from objectives and constraints to monitoring
  • Identify the main institutional and individual investor types in Ethiopia and what drives each
  • Calculate holding-period return and convert nominal returns to real returns under high inflation
  • Calculate the standard deviation of returns and explain what it says about risk
